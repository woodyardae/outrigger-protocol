# Changelog

## [v0.2.0] - 2026-10-29

### Outrigger Protocol (OPS-1)
- Zero-Dependency CLI built strictly on Python standard library.
- Fail-Closed Boundary Gate (`outrigger check`) verifying diffs against `.outrigger/manifest.json`.
- Secret Leakage Prevention scanning patch hunks for GitHub PATs, Slack tokens, and private keys.
- OPS-1 Report Certification (`outrigger verify`) with strict 15-section level-2 Markdown headers.
- Drop-in Composite GitHub Action (`woodyardae/outrigger-protocol@v0.2.0`).
- Documentation hub live at https://outrigger.alanwoodyard.com.
